# How It Works: UI Design & Interactivity (การแก้ปัญหาสีและการทำปุ่มให้กดได้)

เอกสารนี้อธิบายที่มาของปัญหาสีในหน้าจอที่คุณพบ (จากภาพถ่ายหน้าจอ) และแนวทางการแก้ไข พร้อมทั้งอธิบายวิธีการเขียนโค้ดให้ปุ่มต่างๆ สามารถคลิกใช้งานได้จริง

---

## 1. สาเหตุที่หน้าจอมีสีดำทะมึน และอ่านยาก (Dark Mode Conflict)
จากภาพที่คุณแคปเจอร์มา พื้นหลังของเนื้อหากลายเป็นสีดำสนิท (`#0a0a0a`) ในขณะที่การ์ดตารางเป็นสีขาว ทำให้สีขัดแย้งกันอย่างรุนแรงและอ่านตัวหนังสือแทบไม่ออก

### สาเหตุที่เกิดขึ้น:
ในไฟล์ `admin-web/src/app/globals.css` เริ่มต้นของ Next.js มีคำสั่งนี้ซ่อนอยู่:
```css
@media (prefers-color-scheme: dark) {
  :root {
    --background: #0a0a0a; /* ดำสนิท */
    --foreground: #ededed;
  }
}
```
เมื่อเบราว์เซอร์หรือ Windows ของคุณตั้งค่าเป็น **Dark Mode** ระบบ Next.js จะสั่งให้พื้นหลังกลายเป็นสีดำทันที แต่เนื่องจากเราเขียนหน้าต่างเว็บเป็นโทนสว่าง (Light Theme) การแสดงผลจึงตีกันเอง

### วิธีที่เราแก้ไข:
1. เราได้นำบล็อก `@media (prefers-color-scheme: dark)` ออกจาก `globals.css`
2. กำหนดพื้นหลังหลักของโปรเจกต์ให้เป็น **`bg-slate-100`** (สีเทาอ่อน สบายตา และมีคอนทราสต์ที่พอดีกับการ์ดสีขาว)
3. กำหนดสีตัวหนังสือหลักเป็น **`text-slate-900`** (สีน้ำเงินเข้มเกือบดำ) เพื่อให้อ่านง่าย คมชัด และไม่แสบตา

---

## 2. การทำให้ปุ่มต่างๆ "กดใช้งานได้จริง" (Interactivity)

เดิมทีปุ่มต่างๆ เป็นเพียงรูปไอคอนตกแต่ง ตอนนี้เราได้ใส่ Logic ของ React เข้าไปเพื่อให้ทุกปุ่มทำงานได้จริง:

### A. ช่องค้นหา (Real-time Search)
ใช้ `useState` ผูกกับช่องพิมพ์ เมื่อผู้ใช้พิมพ์ข้อความ ระบบจะนำไปกรอง (Filter) ทันที:
```jsx
const filteredContents = contents.filter((item) => {
  return item.title.toLowerCase().includes(searchTerm.toLowerCase());
});
```
ผลลัพธ์: ตารางจะลดจำนวนแถวลงตามคำที่คุณพิมพ์แบบทันทีโดยไม่ต้องกด Enter หรือรีเฟรชหน้าเว็บ

### B. ปุ่มกรองสถานะ (Filter Status)
เมื่อคลิกปุ่ม **Filter Status** เมนู Popover จะเด้งลงมาให้เลือก:
- ทั้งหมด (ALL)
- PLANNING
- PRODUCTION
- REVIEW
- PUBLISHED

เมื่อคลิกเลือกสถานะใด ตารางจะแสดงเฉพาะงานในสถานะนั้นๆ และมีปุ่ม "รีเซ็ต" ขึ้นมาให้กดล้างตัวกรอง

### C. ปุ่มสร้าง Content ใหม่ (`+ สร้าง Content ใหม่`)
เมื่อคลิกปุ่มนี้ ตัวแปร `isAddModalOpen` จะกลายเป็น `true` และหน้าต่าง Popup (Modal) สีขาวจะเด้งขึ้นมาตรงกลางหน้าจอ พร้อมฟอร์มให้กรอก:
- ชื่อ Content
- เลือกแพลตฟอร์ม (TikTok / YouTube / Instagram)
- กำหนดส่งงาน และผู้รับผิดชอบ
- เมื่อกด **"บันทึก"** ข้อมูลใหม่จะถูกแทรกลงในตารางด้านบนสุดทันที!

### D. ปุ่มดูรายละเอียด (ไอคอนรูปดวงตา 👁️)
เมื่อกดที่รูปตา จะมีหน้าต่างแสดงข้อมูลเชิงลึกของคอนเทนต์นั้นๆ ขึ้นมา พร้อมทั้งมีปุ่ม **"อัปเดตสถานะงานด่วน"** ให้สามารถกดสลับสถานะจาก PLANNING -> REVIEW -> PUBLISHED ได้ทันทีในหน้านั้นเลย

### E. เมนู 3 จุด (⋯) และการลบงาน
เมื่อคลิกที่จุดสามจุดท้ายตาราง จะมีเมนูดรอปดาวน์ให้:
- สลับสถานะงานแบบด่วน
- **ลบ Content นี้ (ปุ่มสีแดง)**: เมื่อคลิก จะมีหน้าต่างถามยืนยันก่อนลบออกจากตารางจริง

---

## 3. สิ่งที่ควรทดลองทำบนหน้าเว็บตอนนี้
คุณสามารถเปิดเบราว์เซอร์ไปที่ `http://localhost:3000/contents` และ `http://localhost:3000/users` เพื่อทดลองเล่นฟังก์ชันเหล่านี้:
1. ลองพิมพ์ค้นหาในช่อง Search
2. ลองกดปุ่ม **"สร้าง Content ใหม่"** แล้วกรอกข้อมูลดู
3. ลองคลิกที่ปุ่ม **Role (เช่น MEMBER ⟳)** ในหน้า Users & Teams เพื่อดูการสลับตำแหน่งแบบเรียลไทม์
4. ลองคลิกที่รูป **ดวงตา (Eye)** เพื่อดู Modal รายละเอียดงาน
